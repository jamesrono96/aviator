# Aviator Classroom Research Prototype V3

V3 improves the research demonstration with:
- visible aircraft trajectory and crash animation
- immediate simulated deposit/withdrawal balance updates
- phone/password account UI
- simulated one-time-code verification
- up to five bet entries per round
- continuous 15-outcome experimental cycling
- audio cues

The account, wallet, and OTP are simulated for classroom research. No real payment rails, operator APIs, or real-money wagering are implemented.
